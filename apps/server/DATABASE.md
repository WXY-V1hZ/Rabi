# Server 数据库设计

## `executor`

| 字段                              | 用途                                                                                                            |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `id`                              | 稳定的 `executorId`，供会话引用。                                                                               |
| `user_id`                         | 所属 Rabi 账号，外键引用 `user.id`。                                                                            |
| `executor_identity_secret_digest` | Executor 身份密钥摘要，全局唯一。CLI 丢失签发响应时，可凭事先保存的身份密钥定位原记录，由原账号批准后换发凭据。 |
| `access_token_digest`             | 当前连接凭据的摘要。换发时替换此摘要，旧 access token 随即失效。                                                |
| `access_token_expires_at`         | 当前连接凭据的到期时间。每次签发有效 30 天，到期后由用户重新授权。                                              |
| `access_token_revoked_at`         | 当前连接凭据的撤销时间。撤销后，原账号仍可批准换发。                                                            |
| `unbound_at`                      | Executor 的解绑时间。旧会话继续引用原记录，旧身份密钥失去恢复该绑定的资格。                                     |
