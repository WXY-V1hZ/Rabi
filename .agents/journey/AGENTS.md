# 项目进度与历史

本目录保存任务目标、验收结果和提交历史。接续工作时，读取 `CURRENT` 指向的任务文档。

- 新建任务文档时，复制 [TEMPLATE.md](TEMPLATE.md)，填写任务信息，并按用户当地的创建日期存放在 `YYYYMMDD/`。跨日继续更新原文档。
- 任务文档以行为、前置条件和验收结果描述进度。定位文件时，用 `git log -- <任务文档>` 找相关提交，再用 `git show --stat <提交>` 查看当时改动的文件。
- 任务相关提交在同一提交中追加完成的行为和实际验证结果。
- 用户确认验收后，在原任务文档记录结果，将 `NEXT` 提升为 `CURRENT`，将 `NEXT` 指向用户选定的下一项。
- 暂缓补充项或替换 `NEXT` 时，在 [BACKLOG.md](BACKLOG.md) 用自然语言记录任务名称、待解决的行为、暂缓原因和恢复条件。恢复已有任务时复用原文档。
